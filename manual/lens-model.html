Reference

How the lenses are defined

Every optical quantity RIA uses, where it comes from, and how to describe your own array.

A lens is a plain record

A lens is described by three numbers, and an array is a list of such records:

{"position": (x, y),   # lens centre on the lens plane, mm
 "f": 9.0,             # focal length, mm
 "aperture": 1.5}      # lens radius, mm

The list goes to addLens together with the one array-wide optical parameter, the residual blur floor σ₀ that every blob carries regardless of focus (diffraction, finite optics, sensor response):

system.addLens(lenses=[{"position": (0.0, 0.0), "f": 9.0, "aperture": 1.5},    # one record per lens
                       {"position": (3.6, 0.0), "f": 12.0, "aperture": 1.5}],  # centre mm, f mm, radius mm
               blur_floor=0.12)                                                # array-wide sigma_0, mm

A helper generates the hex-packed positions the examples use; it returns positions only, so focal lengths and apertures stay explicit in your code:

ria.hex_layout(rings=3, pitch=3.6)   # hex-packed centres: 1 ring → 7 lenses,
                                     # 2 → 19, 3 → 37

Where a lens puts its blob — the chief ray

Let u be the distance from the source to the lens plane. On the imaging side this is u = working_distance + z, because the scintillator's z is measured from its front face. The chief ray through lens i crosses the sensor at

centre_i = lens_i + (S*/u) * (source_xy - lens_i)   # chief ray: blob centre on the sensor

Depth enters only through the magnification S*/u. That single factor is what lets a flat array measure depth: different depths shift the blobs by different amounts, and the pattern of shifts is what the inversion reads.

How big the blob is — defocus

With the thin-lens image distance d_i = f_i·u / (u − f_i), the blur radius is

sigma_i = (a_i/2) * |S* - d_i| / d_i  +  sigma_0    # defocus blur + the floor, mm

A lens is sharp only where its image distance matches the sensor distance (d_i ≈ S*); everywhere else it blurs. A focal length is therefore a vote for one depth, and an array whose focal lengths differ covers the depth range. With the reference values, a lens with f = 12 viewing a source 30 mm from the lens plane has σ = 0.138 mm (nearly in focus), while an f = 6 lens viewing the same source has σ = 1.42 mm.

From blob to pixel values

Each lens contributes a Gaussian blob with the centre and width above, weighted by the solid angle it subtends, a_i²/u². A pixel's expected value is the blob density at the pixel centre times the pixel area, with the pixel's own second moment w²/12 folded into the Gaussian variance (w the pixel width). This is a density, not an error-function integral over the pixel — deliberately, because the same expression is emitted symbolically to the solver, and the solver's operator set has exp, sqrt and ratios but no erf. Forward simulation and inversion therefore use the identical formula, term for term.

The design-side view of the same array

The design functions (Fisher information, CRB, focal-length optimisation) take a LensArray, built from the same lens records plus the system-wide quantities they need:

array = ria.LensArray(lenses=LENSES,          # same records as addLens
                      blur_floor=0.12,        # same sigma_0, mm
                      imaging_distance=20.477,# lens plane -> sensor, mm (S*)
                      sensor_size=(46.15, 32.84))   # active area, mm

On the design side z is the source's distance from the lens plane directly (the design-side convention), and sources are parameterised by lateral radius r on the +x axis. The four design functions — exactly as example 6 calls them, over a grid of test radii and depths:

radii  = (5, 10, 15, 20, 25)          # source lateral radius r, mm
depths = tuple(range(10, 51, 5))      # source depth z, mm
photons = 100                         # N_gamma per event

ria.design_score(array, radii, depths, photons)         # -> mean log CRB over the grid
    # (lower = better geometric-mean depth precision)

ria.crb_map(array, radii, depths, photons)              # -> (..., ..., M)
    # M: the per-point log CRB map behind the figures

ria.optimise_focal_lengths(array, radii, depths, photons,   # coordinate-descent sweep
                           f_range=(3.0, 16.0), rounds=4)   # manufacturable f, 4 passes
    # -> (array, score): the specialist baseline

ria.optimise_focal_lengths_rekin(array, radii, depths, photons,  # the solver design
                                 f_range=(3.0, 16.0), budget=240,  # solve budget, s
                                 keep_model="design.rn")           # keep the emitted model
    # -> (array, status, obj); objective="minimax" minimises the
    #    WORST log CRB anywhere — no sweep analogue

violations() checks a candidate design and returns an empty list when it is feasible, or a description of what is wrong:

array.violations(min_sep=3.5, f_range=(3.0, 16.0))   # check a candidate design
# []                                        <- feasible
# ['lens spacing 2.90 mm < 3.5 mm']         <- lenses would overlap
# ['focal lengths [2.10, 16.00] outside [3.0, 16.0] mm']
# ['a lens sits outside the mounting area']

The three constraints are pairwise separation, the focal-length range, and every lens inside the mounting area.

Model fidelity. This is the paraxial chief-ray approximation: each lens is collapsed to a single ray plus a circular Gaussian. It is exact on-axis; a real lens draws an ellipse off-axis (coma, astigmatism), and the model over-trusts focus at shallow depth. The trade is deliberate — everything above is closed form, so it can be differentiated, emitted as algebra, and evaluated millions of times inside a design optimisation. For final numbers, calibrate against measurement or a ray tracer.
